## 🔬 Hardware e sistemas embarcados

- **[tcc-filtro-pdm-asic](https://github.com/raissacrispim/tcc-filtro-pdm-asic)** (TCC):
  ASIC de um filtro digital (CIC + FIR) para sinais ultrassônicos PDM, do RTL
  ao layout em 32 nm. Verificação contra Golden Model em Python, DFT com ATPG
  (98,57% stuck-at), timing fechado em 3 corners e DRC/LVS limpos. Versão
  registrada no INPI.
- **[motor-sistemas-embarcados](https://github.com/raissacrispim/motor-sistemas-embarcados)**:
  controle digital de velocidade de motor CC com ESP32. Modelo da planta
  identificado a partir de ensaios reais, controlador PI discretizado por
  Tustin, FreeRTOS e interface com display OLED para ajustar os ganhos em
  tempo real.
